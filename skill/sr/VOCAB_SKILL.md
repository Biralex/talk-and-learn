# Serbian Video Vocabulary

Получает транскрипт сербского YouTube-видео, отбирает полезную лексику для начинающего и добавляет слова в сербскую базу повторений.

## Для кого эта лексика

Пользователь русскоговорящий и учит сербский **с нуля** (A1, постепенно A2–B1) для живого общения. Ему нужна **самая частая разговорная лексика**: бытовые глаголы, существительные, прилагательные, наречия, вежливые фразы, устойчивые выражения. Редкие, книжные, узкоспециальные слова и сленг только засоряют базу. Это правило действует на всё, что ты пишешь в записи: на выбор слов, переводы и примеры.

Сербский близок к русскому. Не трать место в базе на слова, которые пишутся и значат то же, что по-русски (`student`, `problem`, `muzika`, `park`), но **обязательно бери ложных друзей**: слова, похожие на русские, но с другим значением (`trudna` — беременная, `život` — жизнь, `pitati` — спрашивать, `jagoda` — клубника, `vredan` — трудолюбивый или ценный, `čas` — урок или час, `nedelja` — неделя и воскресенье, `kosa` — волосы, `ponos` — гордость).

## Шаги

### 1. Получить транскрипт

Инструменты лежат в MCP-сервере `youtube-connector-mcp` и могут быть **deferred**: сначала загрузи схему через ToolSearch с запросом «youtube transcript». Нужный инструмент — `youtube_get_transcript`. Не угадывай имена параметров.

Параметры: `video_id` (ID видео, а не ссылка целиком) и `language`: сначала `sr`. Если сербского транскрипта нет, посмотри `availableTracks` и возьми `hr`, `bs` или `sh` (хорватский, боснийский, сербохорватский — это фактически тот же язык). ID достань из ссылки: для `youtube.com/watch?v=XXXXXXXXXXX` это значение `v`, для `youtu.be/XXXXXXXXXXX` — последний сегмент пути (11 символов, параметры вроде `&t=` или `?si=` в него не входят).

Запомни **чистую ссылку на видео** вида `https://www.youtube.com/watch?v=XXXXXXXXXXX`: она понадобится в шаге 5 как `source_url`.

Название видео для имени файла возьми через `youtube_get_video` (поле `snippet.title`, тот же MCP-сервер).

Если транскрипт недоступен или он не на сербском (хорватском, боснийском), сообщи пользователю и остановись.

**Транскрипт может быть кириллицей:** это нормально, `prepare_words` сам переведёт его в латиницу.

**Если ответ слишком большой.** Для длинного видео (примерно от 30–40 минут) `youtube_get_transcript` может вернуть ошибку вроде «result (N characters) exceeds maximum allowed tokens. Output has been saved to <путь>». Это штатная ситуация: весь ответ сохранён во временный файл. Не вызывай инструмент повторно и не читай этот файл в контекст целиком. Файл — JSON в одну строку, работай с ним через `jq` в Bash. Структура: `{data: {videoId, language, text, segments, segmentCount, availableTracks}, error, pagination}`.

1. Достань только полный текст: `jq -r '.data.text' <путь> > <файл из шага 2>`. Поле `data.segments` не используй. Сам текст в контекст не выводи.
2. Проверь результат: язык — `jq '.data.language, .data.segmentCount' <путь>`, число слов — `wc -w`, начало и конец файла (`head -c 300`, `tail -c 300`) должны быть началом и концом видео. Если конец обрывается посреди фразы, текст неполный: сообщи пользователю, какая часть не вошла.
3. Дальше действуй по шагу 2.

### 2. Сохранить транскрипт в файл

Сохрани текст в папку `data/transcribation/sr/` внутри проекта LangHelper (talk-and-learn) — того, из которого запущен MCP-сервер `langhelper`. Если полный путь к проекту тебе неизвестен, спроси у пользователя один раз.

**Обычное видео — один файл:** `{название_видео}.txt`.

**Длинное видео — несколько файлов.** Для начинающего кандидатов из длинного видео слишком много, поэтому если в транскрипте больше 3000 слов (около 20 минут речи), раздели его на части примерно по 3000 слов: `{название_видео}_part_1.txt`, `{название_видео}_part_2.txt` и так далее. Режь по границам предложений. Предложи пользователю начать с первой части и спроси, обрабатывать ли остальные сразу.

Имя файла — название видео, очищенное от символов `/ \ : * ? " < > |`. Если файл уже существует, перезаписывай. Формат — просто текст транскрипта, без заголовка и ссылки.

### 3. Вызвать prepare_words

Инструмент из MCP-сервера `langhelper` (при необходимости загрузи схему через ToolSearch).

```
prepare_words(path="<полный путь к файлу из шага 2>", lang="sr")
```

**Обязательно `lang="sr"`**, иначе текст разберётся как английский. Инструмент вернёт:

```
Candidates: N (words are already in db: M)
---
лемма | окно контекста из транскрипта
```

**Если файлов несколько,** шаги 3–5 выполняй для каждой части по очереди и закончи одну часть полностью (слова добавлены), прежде чем браться за следующую.

### 4. Отобрать слова и составить записи

За **один проход** по списку кандидатов составь записи только для слов, которые стоит учить.

**Пропускай:**
- имена людей, названия мест, компаний, брендов, клубов, групп (Beograd, Partizan, Telekom…);
- аббревиатуры;
- слова, которые совпадают с русскими по написанию и значению (`student`, `park`, `problem`), если только у них нет неожиданного второго значения;
- служебные слова без собственного перевода, числительные выше «десяти», междометия;
- редкие, книжные, узкоспециальные слова и сленг;
- артефакты разбора — слова, которые явно не соответствуют окну контекста.

**Про леммы.** Кандидаты получены хорватской моделью, и для сербского она часто ошибается: путает начальную форму (`kaf` вместо `kafa`, `pijem` вместо `piti`), не узнаёт чисто сербские слова или даёт хорватскую или иекавскую форму. Всегда сверяй лемму с окном и сам записывай правильную **словарную форму, экавскую, латиницей**:
- глагол — инфинитив (`raditi`, `ići`, `moći`, `videti`, не `vidjeti`);
- существительное — именительный падеж единственного числа (`dete`, `reka`, `mleko`);
- прилагательное — мужской род единственного числа (`lep`, `beo`);
- если в видео хорватское слово (`kruh`, `tisuća`, `vlak`), запиши сербское (`hleb`, `hiljada`, `voz`) и упомяни хорватское в переводе: `хлеб (хорв. kruh)`.

**Для каждого подходящего слова составь:**

- `lemma` — словарная форма по правилам выше. Частые устойчивые выражения из видео можно записать целиком: `nema problema`, `hvala lepo`, `kako da ne`.
- `translation` — одно или два **разных по смыслу** ходовых значения на русском через `;`:
  1. первым — значение из видео;
  2. вторым — другое частое значение в обычной речи, если оно есть и отличается по смыслу (не две формы одного и того же);
  3. для глаголов с частой видовой парой укажи вид: `kupiti` → `купить (сов.; несов. kupovati)`;
  4. для ложных друзей добавь пометку: `trudna` → `беременная (не «трудная»!)`.
- `examples` — ровно два примера из разных источников:
  - **Пример 1 — из транскрипта.** Вырежи из окна одно законченное предложение с этим словом, исправь ошибки распознавания и расставь знаки. Если предложение длинное, сократи до самой фразы со словом. Иекавицу в цитате оставь как есть, это живая речь. Если окно испорчено так, что связного предложения не получается, придумай пример сам (редкое исключение).
  - **Пример 2 — всегда придумываешь сам.** Очень простое бытовое предложение до 8 слов уровня A1, экавское, чтобы незнакомым было только само слово. Если у слова два значения, покажи второе.
  - К каждому примеру — естественный перевод на русский.

Примеры можно писать латиницей или кириллицей: сервер всё сохранит латиницей, а пользователю покажет обе азбуки. Пиши латиницей, так меньше путаницы.

**Сколько слов брать.** Для начинающего лучше 20–40 действительно нужных слов из видео, чем 100 случайных. Если подходящих кандидатов гораздо больше, бери самые частые и полезные в быту, остальные пропусти и скажи об этом в итоге.

### 5. Добавить слова через add_words

Инструмент из MCP-сервера `langhelper`. Передавай:
- `entries` — список записей;
- **`lang="sr"`** — обязательно;
- **`source_url`** — чистая ссылка на видео из шага 1, одна на весь вызов. Если видео делилось на части, `source_url` во всех частях один и тот же.

**Порции маленькие: по 15–20 записей за вызов.** Чтобы JSON был валидным:
- не используй двойные кавычки внутри текста: по-русски ставь «ёлочки», по-сербски перефразируй или используй одинарные кавычки; без обратных слэшей и переносов строк внутри значений;
- каждая запись целиком должна войти в порцию;
- после каждого вызова проверяй ответ: число добавленных должно совпасть с отправленными (за вычетом дублей);
- если вызов упал из-за невалидного JSON, считай, что ничего не записано: раздели порцию пополам и отправь заново.

Пример вызова:

```json
{
  "source_url": "https://www.youtube.com/watch?v=XXXXXXXXXXX",
  "lang": "sr",
  "entries": [
    {
      "lemma": "kupiti",
      "translation": "купить (сов.; несов. kupovati)",
      "examples": [
        {"sentence": "Juče sam kupio novi telefon.", "translation": "Вчера я купил новый телефон."},
        {"sentence": "Moram da kupim hleb.", "translation": "Мне нужно купить хлеб."}
      ]
    },
    {
      "lemma": "trudna",
      "translation": "беременная (не «трудная»!)",
      "examples": [
        {"sentence": "Moja sestra je trudna.", "translation": "Моя сестра беременна."},
        {"sentence": "Ona je trudna već pet meseci.", "translation": "Она беременна уже пять месяцев."}
      ]
    }
  ]
}
```

### 6. Сообщить итог

Коротко: сколько слов добавлено, сколько пропущено как дубли и, если было, сколько подходящих слов не взято, чтобы не перегружать. Таблицу слов не выводи, она уже в базе. Добавь, что слова можно повторить командой `python -m src.adhoc.review --lang sr` или посмотреть со звуком: `python -m src.adhoc.browse --lang sr --source <ссылка>`.

Если видео делилось на части, дай одну общую сводку по всему видео.

**Об ошибках и обходных путях говори прямо.** Если по ходу работы была ошибка и пришлось её обходить (транскрипт не поместился и текст достали из файла, транскрипт был хорватский вместо сербского, порция `add_words` не прошла из-за битого JSON), добавь в итог по строке на каждую: что произошло и чем закончилось.

Пример: «Добавлено 28 слов из видео „Kako naručiti kafu u Beogradu“ (https://www.youtube.com/watch?v=XXXXXXXXXXX). Пропущено как дубли: 4. Ещё ~15 редких слов не взял, чтобы не перегружать базу.»
